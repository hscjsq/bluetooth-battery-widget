蓝牙电量小组件
================
本包为便携版：解压到任意文件夹，双击 exe 即用，无需安装、无需 Python。
换电脑直接把整个文件夹拷过去；位置与配色随任务栏自动适配。
第一次使用请先看「快速开始.txt」，细节再看本文件。


程序：BtBatteryWidget.exe（单文件，无需 Python）
配置：config.json，用记事本改完保存；也可在右键菜单里点选即时修改。
右键菜单（在小组件上点右键弹出，只列高频项）：
  立即刷新 / 显示方式（点击切换）/ 显示未连接设备 / 设置 ▸ / 退出。
「设置 ▸」鼠标一悬停就展开二级菜单，低频开关都收在这里，点一下即生效：
  开机自动启动 / 任务栏显示设备名称 / 设备悬停提示 /
  低电量提醒（≤10%）/ 测试气泡提醒 / 重置报警记录（清除冷却）/
  重新对齐（避开天气）/ 设备上下线平滑过渡 / 悬停天气时自动淡出 /
  恢复默认设备顺序 / 显示的设备 ▸（再悬停，逐台开关）/ 打开配置文件。
带勾选项点一下即切换，无需打开独立窗口或额外确认。

设备悬停提示：鼠标停在某台设备上会弹出深色提示框（完整设备名 / 连接状态 /
  电量 / 拖动说明）；右键→设置→「设备悬停提示」可开关。
设备排序：在线设备排前、离线排后；鼠标按住设备项可左右拖动调整顺序，
  顺序写入配置；右键→设置→「恢复默认设备顺序」还原。设备多于 3 台时显示「+N」，
  点它可列出其余设备并置顶。

显示方式（右键「显示方式」点一下循环切换，切换时自动重建窗口）
  display_mode = taskbar_child  默认。真子窗口：以 WS_CHILD 挂到 Explorer 的
                 Shell_TrayWnd 上，紧贴托盘通知区左侧；背景近乎全透明，
                 任务栏底色直接透出。不是浮窗，不会被折叠或遮挡。
                 每秒自检，Explorer 重启后自动重建。
  display_mode = taskbar        同色浮窗横条（旧模式，可回退）
  display_mode = card           任务栏上方的悬浮卡片
  taskbar_overlay               仅 taskbar 浮窗模式有效
  taskbar_child_right_gap       真子窗口右边缘往左让出的像素（默认 200，
                                用于避开任务栏天气小组件，文字重叠时调大）
  tb_max_items          横条最多显示几台设备
  tb_show_name = false  默认。任务栏只画「设备简笔画 + 电量」，不画设备名；
                        改成 true，或右键勾「任务栏显示设备名称」可恢复
  tb_name_chars         显示设备名时最多几个字
  device_icons          手动指定图标，如 {"OMR251 BT2": "mouse"}；
                        可选 headset/gamepad/speaker/mouse/keyboard/bluetooth

设备图标（按 Windows 真实 PnP 类别判定，不再靠设备名猜）
  BLE 主节点只标 "Bluetooth" 类，程序按 ContainerId 找到同一台设备的
  HID / AudioEndpoint 子节点，用 Mouse、Keyboard、MEDIA 类别或蓝牙
  ClassOfDevice 判断类型，再画对应简笔画。
  例：OMR251 BT2 → Mouse 节点 → 鼠标形状；vivo TWS 3e → 耳机形状。
  多通道设备（BT1 / BT2）会共用同一识别结果。
  线稿统一 22 单位设计坐标系 + 8 倍超采样 + 圆头端点 + LANCZOS 缩小；
  修正了旧版按目标尺寸缩放画布、导致 20px 时图标被裁掉一角的问题。
  六种造型：蓝牙 / 鼠标 / 耳机 / 手柄 / 音箱 / 键盘。

自定义图标（把找来的图放进 icons\ 即可，不用重新打包）
  位置：与 BtBatteryWidget.exe 同级的 icons\ 文件夹
  格式：PNG（推荐，必须带透明通道）/ ICO / WebP，正方形，
        64x64 或 128x128 最佳（程序缩到 20px 显示，源文件大些更清晰）
  底色：必须透明，不要白色或纯色方块背景（任务栏是深色，会突兀）
  构图：图形居中，四周留 10~15% 透明边距；线条/色块要粗，别用细密纹理，
        否则缩到 20px 会糊成一团
  配色：白色或浅灰单色线稿 → 自动染成任务栏前景色，深浅色任务栏都适配；
        彩色图 → 原色显示（建议亮色）。icon_style 可强制：
        auto（默认，按图片有无彩色自动判断）/ color（一律原色）/ mono（一律染色）
  按类型命名（6 张可只放其中几张，没放的自动回退自绘线稿）：
        mouse.png / headset.png / gamepad.png / speaker.png /
        keyboard.png / bluetooth.png
  按设备名单独指定（优先于类型图，文件名 = 设备全名）：
        例：OMR251 BT2.png、vivo TWS 3e.png
  生效：放好后右键「立即刷新」或重启程序，换图会自动重载（按文件时间判断）
  当前已放入 5 张白色线稿：mouse / headset / gamepad / speaker / keyboard；
  bluetooth.png 未放，最左侧蓝牙标识仍用自绘线稿，补同名文件即可替换。

鼠标指针
  窗口类显式加载标准箭头光标并自行处理 WM_SETCURSOR，鼠标移到小组件上
  是正常箭头，不会交给任务栏父窗口决定指针形状。

设备过滤（数据层）
  hide_disconnected = true  默认只显示当前已连接的设备，断开后自动从任务栏消失
  主判据：DEVPKEY_Device_IsConnected（{83DA6326-...} pid 15）。
          这是 Windows 对每个 PnP 节点实时维护的连接状态，断开立刻变 0；
          而电量百分比只是「最后一次上报的缓存值」，断开后不会清空。
          一台物理设备会拆成蓝牙主节点 / HID / AudioEndpoint 等多个节点，
          程序按 ContainerId 把整组节点取 OR，任一节点连着就算在线。
  辅助判据：BluetoothAPIs.dll 的 fConnected（经典蓝牙）、音频端点
          DeviceState（1=ACTIVE / 8=UNPLUGGED），任一信号明确在线即算在线。
  以上都没有明确在线证据时一律判为离线（旧版会把「最近连过、查不到信号」
          的设备当成在线显示，所以刚断开的手柄会一直挂在任务栏）。
  右键主菜单「显示未连接设备」可临时查看全部（灰色显示）；「显示的设备」子菜单可逐台屏蔽。

低电量气泡报警（右键「低电量提醒（≤10%）」可开关）
  alert_threshold = 10       电量 ≤ 10% 时触发，数值可改
  alert_duration_seconds = 8 气泡停留秒数；点击气泡任意处可提前关掉
  报警一次的规则（冷却窗口，默认 24 小时）
    alert_cooldown_hours = 24  同一台设备两次报警的最小间隔，可配 1~720 小时
    每台设备在冷却窗口内最多弹一次气泡。以下情况都【不会】重复弹：
      电量一直低于阈值、每 10 秒的定时刷新、设备断开后重连、
      充回阈值以上又跌破、关闭再打开提醒开关、程序重启 / 注销重新登录。
    冷却期满后如果设备仍然低电，才会再提醒一次。多台设备各自独立计时。
    记录写在与 exe 同级的 alert_state.json（设备名 -> 上次报警时间戳），
    跨重启有效、原子写入、文件损坏会自动重建。想立刻解除冷却：
      右键→设置→「重置报警记录（清除冷却）」，或直接删除 alert_state.json。
  只统计在线设备，断开设备残留的缓存电量不会误报。
  多台设备同时低电会合并成一个气泡，最多列 3 行。
  气泡是独立自绘的圆角分层窗口，从任务栏小组件正上方冒出、带指向三角；
  不需要托盘图标，也不依赖系统通知中心（Win11 折叠通知不会漏掉）。
  右键→设置→「测试气泡提醒」用假数据（OMR251 BT2 8%）预览，不影响真实报警状态。

刷新与「新设备马上出现」（三层，互不依赖）
  ① 事件驱动（最快，约 150ms）
     主窗口在 taskbar_child 模式下是挂在 Shell_TrayWnd 上的 WS_CHILD，
     而 Windows 的 WM_DEVICECHANGE 设备插拔广播只发给顶层窗口 —— 这就是
     以前「新设备连上要等好几秒甚至十几秒」的根因。
     现在另建一个不显示的 WS_EX_TOOLWINDOW 顶层窗口代收广播，并用
     RegisterDeviceNotification(GUID_NULL) 订阅所有设备接口类（蓝牙/HID/USB）；
     收到事件后合并成 150ms 一次刷新，避免一台设备连发多个通知造成重复重绘。
  ② 轻量探测（默认 2 秒，兜住「没有 PnP 广播」的情况）
     quick_check_seconds = 2  每 2 秒只做一次 SetupDi 遍历读
     DEVPKEY_Device_IsConnected + 电量（实测约 6ms，几乎不占 CPU），
     生成 (设备名, 电量, 在线) 签名；签名一变立刻完整刷新，签名不变
     什么都不做（不重绘、不闪）。BLE 设备连接有时只是属性翻转、系统
     不发插拔广播，就靠这一层发现。可配 1~60 秒，改完需重启程序。
  ③ 全量兜底（默认 10 秒）
     refresh_seconds = 10  每 10 秒无条件重载配置 + 完整刷新，保证
     配置改动、图标换图、以及前两层都漏掉的变化最终一致。
  断开设备通常 ① 或 ② 就能消失；最坏情况也不会超过 10 秒。
  stale_days       多少天没连接算缓存数据（无实时信号时作为兜底标注）
  max_rows / name_max_chars  卡片模式行数与设备名字符数

操作：双击刷新、右键菜单；卡片模式可左键拖动，真子窗口模式不可拖动。
开机自启：HKCU\Software\Microsoft\Windows\CurrentVersion\Run\BtBatteryWidget
          （右键→设置→「开机自动启动」可直接开关）
卸载：本包为便携版，无需安装、也没有卸载器。先在「设置 ▸」里取消开机自启、
      右键「退出」关闭程序，再删除整个文件夹即可，无注册表或服务残留。

来源与致谢
==========
本工具的 UI 呈现思路（在 Windows 任务栏以「设备简笔画图标 + 电量」展示无线设备
电量）参考了开源项目 Wireless Device Battery Monitor：
  作者：krisgfx9
  仓库：https://github.com/krisgfx9/Wireless-Device-Battery-Monitor
  许可证：GPL-3.0
本项目只借鉴上述呈现方式与功能定位，未复制其任何源代码。设备在线判定、电量读取
（bt_battery.py，基于 Windows SetupAPI / BluetoothAPIs）以及窗口、绘制、动画、
菜单、报警（bt_widget.py）均为独立实现。上游许可证适用于其自身代码，本项目未将其
代码纳入本工具。
其他依赖：Pillow（HPND，图像绘制）、PyInstaller（GPL-2.0-or-later 含打包例外，
用于生成单文件 exe）。icons 目录中的 5 张设备线稿由使用者提供。
